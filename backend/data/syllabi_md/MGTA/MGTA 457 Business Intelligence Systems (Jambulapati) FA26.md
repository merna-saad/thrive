# _MGTA 457: Business Intelligence Systems Vikram Jambulapati_ 

## _Fall 2026_ 

This is a hands-on, project-based course designed to transform highvolume data from disparate systems into real-time, actionable business insights. We will utilize the Databricks Data Intelligence Platform for scalable storage and processing, alongside Power BI for visual analytics. The principles of modern BI architecture, moving from lakehouse to dashboard, are the core of this course.

## _Course Objectives_ 

At the close of this course, you will be able to: 

- Articulate the value of cloud-native BI systems. 

- Manage data lifecycles using Databricks (Loading, Scaling, and Querying). 

- Employ infographic design principles to convey information rapidly. 

- Recognize when design or data modeling may lead to poor interpretation. 

- Combine, cleanse, and model data feeds for production-grade dashboards.

## _Team Project Deliverables_ 

- **Dashboard Design Document** : 2-5 pages with sketches and intended user flow. 

- **Databricks Lakehouse** : A curated set of Unity Catalog tables containing your cleaned, joined datasets. 

- **Power Query / SQL Workflow** : Demonstration of the transformation layer (either via SQL in Databricks or Power Query in Power BI). 

- **Final Presentation** : 10–15 minute story using at least 3 dashboards (Power BI reports) and 6+ visuals.
